# Cybersecurity Guidelines & Operational Procedures

## Version Control Security Rules

1. **No Sensitive Data:** Never commit passwords, API keys, or private keys to GitHub.
2. **Pull Request Reviews:** All code merged into `development` or `main` must pass peer review.
3. **Branch Protection:** Direct commits to `main` are restricted. All changes arrive via Pull Requests.
4. **Audit Logging:** Every commit must reference a valid Freshworks ticket ID.
