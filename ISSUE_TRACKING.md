# Freshworks Issue Tracking Workflow

This document outlines how Freshworks is used alongside GitHub for project management.

## Issue Lifecycle

1. **Open:** Issue logged in Freshworks with clear description.
2. **In Progress:** Developer assigns ticket and creates a feature branch.
3. **Code Review:** Code is committed referencing the ticket ID (`Fixes SCT-1`) and a Pull Request is submitted to `development`.
4. **Resolved:** Ticket marked resolved in Freshworks after PR merge.
